How my LinkedIn posts get made

A GitHub Actions job wakes up on a schedule, gathers material, writes a draft, and then stops and asks me. Nothing reaches LinkedIn until I reply approve. This page is regenerated by that same job, so the numbers below are the live state of the queue.

The job asks to run every 15 minutes. GitHub throttles scheduled jobs on free repos, so measured across the last 60 runs it actually lands ~32 min apart. That figure is measured, not configured.
